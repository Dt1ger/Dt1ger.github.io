How I run an incident

Five stages, in the order they happen.

Skip the walkthrough

Stage 1 of 5Triage

Escalated alerts and incidents come to me. I work the ServiceNow and Microsoft Defender and Sentinel queues, rank each event by risk and potential impact, and decide what needs a full investigation.

  • ServiceNow
  • Defender XDR
  • Sentinel incident queue
  • Splunk

Stage 2 of 5Investigate

I collect evidence across hosts, memory, network and Azure, then build the timeline: how the attacker got in, where they moved, and what they left behind.

  • Volatility 3
  • KAPE
  • Chainsaw
  • Autopsy
  • FTK
  • Packet captures
  • MITRE ATT&CK

Stage 3 of 5Contain

Once the scope is clear, I stop the spread and use network telemetry to check that containment held. Some actions I take myself; others go to IT, Legal, HR, vendors and partners.

  • SOAR playbooks
  • Python
  • PowerShell
  • Firewall, proxy and IDS/IPS telemetry

Stage 4 of 5Eradicate and recover

I drive remediation of what the investigation found and see the incident through recovery, with every analysis step written into the case record.

  • Microsoft 365
  • Entra ID
  • Proofpoint
  • ServiceNow

Stage 5 of 5Learn

Lessons learned go back into the defenses: new or tuned detections, updated playbooks, and training built from the real incident. Then I re-run adversary emulation to confirm the gap is closed.

  • Defender for Endpoint
  • KQL
  • Splunk
  • Breach and Attack Simulation
  • KnowBe4

Three public tools for blue-team work, written in Python. Each panel shows roughly what the tool does; press Replay to run it again.

Pocket Triage

Python and PyQt5, for Windows

A triage and incident-response utility for SOC analysts: rapid endpoint checks, Defender portal access and command execution in one window.

  • Quick endpoint scan with the Microsoft Malicious Software Removal Tool, with the results read back from its log
  • In-app terminal that shows output, errors and exit codes
  • One-click Defender portal, Remote Desktop, VirusTotal and AI-assistant shortcuts
  • No telemetry; all settings stay on the local machine

Threat Intel Bot

Python, scheduled

Pulls articles from threat-intelligence sources, filters them by the keywords you care about, and emails a digest so the reading comes to you.

  • HTML email digest with color-coded keyword tags
  • Runs every three hours on a built-in scheduler
  • Removes duplicates across runs, so no article appears twice
  • Multiple recipients, custom keywords and an activity log

CyberD QR Reader

Python desktop app, ships as a Windows executable

A QR scanner built for security work. It reads the code and hands the link to VirusTotal, so nobody has to open a suspicious URL to find out what it is.

  • Scan with the webcam or drag in an image
  • Extracts and validates the URL or text
  • Sends links straight to VirusTotal for analysis
